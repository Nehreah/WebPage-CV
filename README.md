# Renea Devs — Portafolio

Portafolio personal de Javier Felipe Contreras Díaz (NehReah).

## Uso
1. Descomprime el archivo.
2. Abre `index.html` en un navegador moderno.
3. El modo oscuro se activa de forma predeterminada. Usa el botón de tema en la barra superior para alternar entre modo oscuro y claro; la elección se guarda en el navegador.

## Cambios incluidos
- Modo oscuro como tema predeterminado, con alternancia a modo claro.
- Contrastes reforzados para texto, superficies, bordes y enlaces.
- Nueva presentación sobre código eficiente y ético, investigación cualitativa y cuantitativa, bienestar humano, tecnología inteligente y desarrollo Android para problemas reales.
- Se conservan la ficha personal y los proyectos existentes.
